# Fourth Mode

**Ἦχος Τέταρτος** · Tone 4 in the Sunday cycle

| Base | Genus | Intonation (apechema) |
|---|---|---|
| Vou (Legetos) / Di (Agia) / Pa | diatonic | Ἅγια (Agia); Λέγετος (Legetos) |

Fourth Mode has several faces: Legetos (base Vou, heirmologic and sticheraric), Agia (base Di, papadic), and melodies on Pa. Learn which one a piece is in by checking the opening martyria.

## Drone and scale

Scale from Vou in this vault's model (diatonic), in moria:

`Vou (8)  Ga (12)  Di (12)  Ke (10)  Zo (8)  Ni' (12)  Pa' (10)  Vou'`

```psaltiki-drone
genus: diatonic
base: Vou
```
