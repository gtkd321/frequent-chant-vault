# First Mode

**Ἦχος Πρῶτος** · Tone 1 in the Sunday cycle

| Base | Genus | Intonation (apechema) |
|---|---|---|
| Pa | diatonic | Ἀνανές (Ananes) |

Heirmologic First Mode moves quickly around Pa and Ga with cadences on Pa. Sticheraric First Mode adds long melismas that rise to Di and come back down.

## Drone and scale

Scale from Pa in this vault's model (diatonic), in moria:

`Pa (10)  Vou (8)  Ga (12)  Di (12)  Ke (10)  Zo (8)  Ni' (12)  Pa'`

```psaltiki-drone
genus: diatonic
base: Pa
```
