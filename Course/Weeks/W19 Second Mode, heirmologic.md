# Week 19 · Second Mode, heirmologic

Block 3 · The chromatic modes

**Goal:** Read quick Second Mode melodies with base Di, including the hard-chromatic heirmologic coloring.

**Mode:** [[Second Mode]] (Ἦχος Δεύτερος), base Di, soft chromatic. Intonation: Νεανές (Neanes).

## Days

### Day 109 (Monday)

[Second Mode heirmologic (hard) formulae](https://music.samonastery.org/Formula2h.pdf): sing 6.

### Day 110 (Tuesday)

Read [Second Mode, God is the Lord](https://music.samonastery.org/Orthros/b3200_God_Is_Lord.pdf).

### Day 111 (Wednesday)

Read the [Second Mode Apolytikion](https://music.samonastery.org/Orthros/b3205_Apolytikion.pdf) (Ὅτε κατῆλθες), parallagi then melos.

### Day 112 (Thursday)

Read the [Second Mode Kathismata](https://music.samonastery.org/Orthros/b3210_Kathismata.pdf), first page.

### Day 113 (Friday)

Find Ὅτε κατῆλθες in Greek on the [Digital Chant Stand](https://dcs.goarch.org/goa/dcs/dcs.html) or in your Anastasimatarion, and read it from the score.

### Day 114 (Saturday)

Cold check: read the [Second Mode Brief Lauds](https://music.samonastery.org/Orthros/b3290_Brief_Lauds.pdf). Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
