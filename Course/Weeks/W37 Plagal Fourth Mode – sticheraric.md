# Week 37 · Plagal Fourth Mode: sticheraric

Block 4 · All eight modes, two tempos

**Goal:** Read Plagal Fourth Mode at sticheraric tempo, using Vespers material.

**Mode:** [[Plagal Fourth Mode]] (Ἦχος Πλάγιος τοῦ Τετάρτου), base Ni, diatonic. Intonation: Νεάγιε (Neagie).

## Days

### Day 217 (Monday)

Sing 8 formulae from the [sticheraric formulae page](https://stanthonysmonastery.org/pages/byzantine-music-formulae) (Plagal Fourth list).

### Day 218 (Tuesday)

Read [Lord, I have cried](https://music.samonastery.org/Vespers/b2800_Lord_I_have_cried.pdf) in parallagi, then melos.

### Day 219 (Wednesday)

Read the [stichera](https://music.samonastery.org/Vespers/b2820_Stichera.pdf): one sticheron.

### Day 220 (Thursday)

Read the [Dogmatikon](https://music.samonastery.org/Vespers/b2840_Dogmatikon.pdf), first half.

### Day 221 (Friday)

Read the [Aposticha](https://music.samonastery.org/Vespers/b2850_Aposticha.pdf). Mark the cadences first, then sing.

### Day 222 (Saturday)

Cold Greek read. On the [Digital Chant Stand](https://dcs.goarch.org/goa/dcs/dcs.html), find a sticheron in this mode (Saturday Vespers or Lauds) and sight-read it. Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
