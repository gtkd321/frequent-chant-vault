# Week 31 · Plagal First Mode: sticheraric

Block 4 · All eight modes, two tempos

**Goal:** Read Plagal First Mode at sticheraric tempo, using Vespers material.

**Mode:** [[Plagal First Mode]] (Ἦχος Πλάγιος τοῦ Πρώτου), base Pa (low Ke in some melodies), diatonic. Intonation: Ἀνεανές (Aneanes).

## Days

### Day 181 (Monday)

Sing 8 formulae from [Plagal First Mode sticheraric formulae](https://music.samonastery.org/Formula5.pdf).

### Day 182 (Tuesday)

Read [Lord, I have cried](https://music.samonastery.org/Vespers/b2500_Lord_I_have_cried.pdf) in parallagi, then melos.

### Day 183 (Wednesday)

Read the [stichera](https://music.samonastery.org/Vespers/b2520_Stichera.pdf): one sticheron.

### Day 184 (Thursday)

Read the [Dogmatikon](https://music.samonastery.org/Vespers/b2540_Dogmatikon.pdf), first half.

### Day 185 (Friday)

Read the [Aposticha](https://music.samonastery.org/Vespers/b2550_Aposticha.pdf). Mark the cadences first, then sing.

### Day 186 (Saturday)

Cold Greek read. On the [Digital Chant Stand](https://dcs.goarch.org/goa/dcs/dcs.html), find a sticheron in this mode (Saturday Vespers or Lauds) and sight-read it. Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
