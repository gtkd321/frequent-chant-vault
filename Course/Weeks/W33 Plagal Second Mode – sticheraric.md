# Week 33 · Plagal Second Mode: sticheraric

Block 4 · All eight modes, two tempos

**Goal:** Read Plagal Second Mode at sticheraric tempo, using Vespers material.

**Mode:** [[Plagal Second Mode]] (Ἦχος Πλάγιος τοῦ Δευτέρου), base Pa, hard chromatic. Intonation: Νεχεανές (Necheanes).

## Days

### Day 193 (Monday)

Sing 8 formulae from [Plagal Second Mode sticheraric formulae](https://music.samonastery.org/Formula6.pdf).

### Day 194 (Tuesday)

Read [Lord, I have cried](https://music.samonastery.org/Vespers/b2600_Lord_I_have_cried.pdf) in parallagi, then melos.

### Day 195 (Wednesday)

Read the [stichera](https://music.samonastery.org/Vespers/b2620_Stichera.pdf): one sticheron.

### Day 196 (Thursday)

Read the [Dogmatikon](https://music.samonastery.org/Vespers/b2640_Dogmatikon.pdf), first half.

### Day 197 (Friday)

Read the [Aposticha](https://music.samonastery.org/Vespers/b2650_Aposticha.pdf). Mark the cadences first, then sing.

### Day 198 (Saturday)

Cold Greek read. On the [Digital Chant Stand](https://dcs.goarch.org/goa/dcs/dcs.html), find a sticheron in this mode (Saturday Vespers or Lauds) and sight-read it. Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
