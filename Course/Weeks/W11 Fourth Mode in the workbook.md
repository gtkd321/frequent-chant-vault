# Week 11 · Fourth Mode in the workbook

Block 2 · Hymns in six modes (workbook)

**Goal:** Read the workbook's Fourth Mode hymns (Ἦχος Τέταρτος), with base Vou (Legetos) / Di (Agia) / Pa and the diatonic genus.

**Mode:** [[Fourth Mode]] (Ἦχος Τέταρτος), base Vou (Legetos) / Di (Agia) / Pa, diatonic. Intonation: Ἅγια (Agia); Λέγετος (Legetos).

These are Legetos melodies on Vou. Notice how Vou works as both the base and the final note.
