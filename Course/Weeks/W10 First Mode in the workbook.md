# Week 10 · First Mode in the workbook

Block 2 · Hymns in six modes (workbook)

**Goal:** Read the workbook's First Mode hymns (Ἦχος Πρῶτος), with base Pa and the diatonic genus.

**Mode:** [[First Mode]] (Ἦχος Πρῶτος), base Pa, diatonic. Intonation: Ἀνανές (Ananes).

## Days

### Day 55 (Monday)
