# Week 29 · Fourth Mode: sticheraric

Block 4 · All eight modes, two tempos

**Goal:** Read Fourth Mode at sticheraric tempo, using Vespers material.

**Mode:** [[Fourth Mode]] (Ἦχος Τέταρτος), base Vou (Legetos) / Di (Agia) / Pa, diatonic. Intonation: Ἅγια (Agia); Λέγετος (Legetos).

## Days

### Day 169 (Monday)

Sing 8 formulae from [Fourth Mode sticheraric formulae](https://music.samonastery.org/Formula4.pdf).

### Day 170 (Tuesday)

Read [Lord, I have cried](https://music.samonastery.org/Vespers/b2400_Lord_I_have_cried.pdf) in parallagi, then melos.

### Day 171 (Wednesday)

Read the [stichera](https://music.samonastery.org/Vespers/b2420_Stichera.pdf): one sticheron.

### Day 172 (Thursday)

Read the [Dogmatikon](https://music.samonastery.org/Vespers/b2440_Dogmatikon.pdf), first half.

### Day 173 (Friday)

Read the [Aposticha](https://music.samonastery.org/Vespers/b2450_Aposticha.pdf). Mark the cadences first, then sing.

### Day 174 (Saturday)

Cold Greek read. On the [Digital Chant Stand](https://dcs.goarch.org/goa/dcs/dcs.html), find a sticheron in this mode (Saturday Vespers or Lauds) and sight-read it. Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
