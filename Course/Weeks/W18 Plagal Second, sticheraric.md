# Week 18 · Plagal Second, sticheraric

Block 3 · The chromatic modes

**Goal:** Read the slower sticheraric Plagal Second: Lord, I have cried, and the stichera.

**Mode:** [[Plagal Second Mode]] (Ἦχος Πλάγιος τοῦ Δευτέρου), base Pa, hard chromatic. Intonation: Νεχεανές (Necheanes).

## Days

### Day 103 (Monday)

[Plagal Second sticheraric formulae](https://music.samonastery.org/Formula6.pdf): sing 6.

### Day 104 (Tuesday)

Read [Plagal Second, Lord I have cried](https://music.samonastery.org/Vespers/b2600_Lord_I_have_cried.pdf) in parallagi.

### Day 105 (Wednesday)

Read the [Plagal Second stichera](https://music.samonastery.org/Vespers/b2620_Stichera.pdf), the first sticheron.

### Day 106 (Thursday)

Read the [Plagal Second Dogmatikon](https://music.samonastery.org/Vespers/b2640_Dogmatikon.pdf), first half.

### Day 107 (Friday)

[Plagal Second verse formulae](https://music.samonastery.org/Formula6v.pdf): sing 4, then apply them to one psalm verse from Lord, I have cried.

### Day 108 (Saturday)

Cold check: read the [Plagal Second Aposticha](https://music.samonastery.org/Vespers/b2650_Aposticha.pdf). Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
