# Week 12 · Plagal First Mode in the workbook

Block 2 · Hymns in six modes (workbook)

**Goal:** Read the workbook's Plagal First Mode hymns (Ἦχος Πλάγιος τοῦ Πρώτου), with base Pa (low Ke in some melodies) and the diatonic genus.

**Mode:** [[Plagal First Mode]] (Ἦχος Πλάγιος τοῦ Πρώτου), base Pa (low Ke in some melodies), diatonic. Intonation: Ἀνεανές (Aneanes).

Only five hymns this week, so days 4–5 repeat the two you sang worst.
