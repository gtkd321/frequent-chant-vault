# Week 25 · Second Mode: sticheraric

Block 4 · All eight modes, two tempos

**Goal:** Read Second Mode at sticheraric tempo, using Vespers material.

**Mode:** [[Second Mode]] (Ἦχος Δεύτερος), base Di, soft chromatic. Intonation: Νεανές (Neanes).

## Days

### Day 145 (Monday)

Sing 8 formulae from [Second Mode sticheraric formulae](https://music.samonastery.org/Formula2.pdf).

### Day 146 (Tuesday)

Read [Lord, I have cried](https://music.samonastery.org/Vespers/b2200_Lord_I_have_cried.pdf) in parallagi, then melos.

### Day 147 (Wednesday)

Read the [stichera](https://music.samonastery.org/Vespers/b2220_Stichera.pdf): one sticheron.

### Day 148 (Thursday)

Read the [Dogmatikon](https://music.samonastery.org/Vespers/b2240_Dogmatikon.pdf), first half.

### Day 149 (Friday)

Read the [Aposticha](https://music.samonastery.org/Vespers/b2250_Aposticha.pdf). Mark the cadences first, then sing.

### Day 150 (Saturday)

Cold Greek read. On the [Digital Chant Stand](https://dcs.goarch.org/goa/dcs/dcs.html), find a sticheron in this mode (Saturday Vespers or Lauds) and sight-read it. Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
