# Week 23 · First Mode: sticheraric

Block 4 · All eight modes, two tempos

**Goal:** Read First Mode at sticheraric tempo, using Vespers material.

**Mode:** [[First Mode]] (Ἦχος Πρῶτος), base Pa, diatonic. Intonation: Ἀνανές (Ananes).

## Days

### Day 133 (Monday)

Sing 8 formulae from [First Mode sticheraric formulae](https://music.samonastery.org/Formula1.pdf).

### Day 134 (Tuesday)

Read [Lord, I have cried](https://music.samonastery.org/Vespers/b2100_Lord_I_have_cried.pdf) in parallagi, then melos.

### Day 135 (Wednesday)

Read the [stichera](https://music.samonastery.org/Vespers/b2120_Stichera.pdf): one sticheron.

### Day 136 (Thursday)

Read the [Dogmatikon](https://music.samonastery.org/Vespers/b2140_Dogmatikon.pdf), first half.

### Day 137 (Friday)

Read the [Aposticha](https://music.samonastery.org/Vespers/b2150_Aposticha.pdf). Mark the cadences first, then sing.

### Day 138 (Saturday)

Cold Greek read. On the [Digital Chant Stand](https://dcs.goarch.org/goa/dcs/dcs.html), find a sticheron in this mode (Saturday Vespers or Lauds) and sight-read it. Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
