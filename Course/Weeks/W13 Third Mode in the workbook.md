# Week 13 · Third Mode in the workbook

Block 2 · Hymns in six modes (workbook)

**Goal:** Read the workbook's Third Mode hymns (Ἦχος Τρίτος), with base Ga and the enharmonic genus.

**Mode:** [[Third Mode]] (Ἦχος Τρίτος), base Ga, enharmonic. Intonation: Νανά (Nana).

This is your first enharmonic mode. Before each hymn, tune Zo against the enharmonic drone.
