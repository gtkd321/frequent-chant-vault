# Week 20 · Second Mode, sticheraric

Block 3 · The chromatic modes

**Goal:** Read the soft chromatic Second Mode at sticheraric tempo.

**Mode:** [[Second Mode]] (Ἦχος Δεύτερος), base Di, soft chromatic. Intonation: Νεανές (Neanes).

## Days

### Day 115 (Monday)

[Second Mode (soft) formulae](https://music.samonastery.org/Formula2s.pdf) and [Second Mode sticheraric formulae](https://music.samonastery.org/Formula2.pdf): sing 6.

### Day 116 (Tuesday)

Read [Second Mode, Lord I have cried](https://music.samonastery.org/Vespers/b2200_Lord_I_have_cried.pdf).

### Day 117 (Wednesday)

Read the [Second Mode stichera](https://music.samonastery.org/Vespers/b2220_Stichera.pdf), the first sticheron.

### Day 118 (Thursday)

Read the [Second Mode Dogmatikon](https://music.samonastery.org/Vespers/b2240_Dogmatikon.pdf), first half.

### Day 119 (Friday)

[Second Mode verse formulae](https://music.samonastery.org/Formula2v.pdf): sing 4, then apply them to a psalm verse.

### Day 120 (Saturday)

Cold check: read the [Second Mode Aposticha](https://music.samonastery.org/Vespers/b2250_Aposticha.pdf). Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
