# Week 27 · Third Mode: sticheraric

Block 4 · All eight modes, two tempos

**Goal:** Read Third Mode at sticheraric tempo, using Vespers material.

**Mode:** [[Third Mode]] (Ἦχος Τρίτος), base Ga, enharmonic. Intonation: Νανά (Nana).

## Days

### Day 157 (Monday)

Sing 8 formulae from [Third Mode sticheraric formulae](https://music.samonastery.org/Formula3.pdf).

### Day 158 (Tuesday)

Read [Lord, I have cried](https://music.samonastery.org/Vespers/b2300_Lord_I_have_cried.pdf) in parallagi, then melos.

### Day 159 (Wednesday)

Read the [stichera](https://music.samonastery.org/Vespers/b2320_Stichera.pdf): one sticheron.

### Day 160 (Thursday)

Read the [Dogmatikon](https://music.samonastery.org/Vespers/b2340_Dogmatikon.pdf), first half.

### Day 161 (Friday)

Read the [Aposticha](https://music.samonastery.org/Vespers/b2350_Aposticha.pdf). Mark the cadences first, then sing.

### Day 162 (Saturday)

Cold Greek read. On the [Digital Chant Stand](https://dcs.goarch.org/goa/dcs/dcs.html), find a sticheron in this mode (Saturday Vespers or Lauds) and sight-read it. Log a 1–5 rating.

### Sunday

Service day. Chant, listen, and write one line in your log. No new lesson.
